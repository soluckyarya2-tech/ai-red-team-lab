# F4: RAG Citation Cross-User Exfiltration — WITHDRAWN

**Status:** hypothesis withdrawn 2026-09-29.

Original hypothesis: file contents surfaced via RAG citation blocks
("document":[...]) could exfiltrate one user's data to another user.

Reality check during the F2 re-test: citations were only ever observed in the
file owner's own chat (normal RAG behavior). The cross-user leg depended on
F2 being a real bypass — which the re-test disproved.

Withdrawn rather than left vague: a findings list should not contain
unverified claims.
